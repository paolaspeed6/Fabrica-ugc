the owner (2026-10-15 21:49) shared the Chrome Web Store extension "Konkur - análise de concorrência" (https://chromewebstore.google.com/detail/pplhjhiggieglpdjkjlinhingidhnihk) made by a friend. It compares products, shows which variation sold most, when a listing was created, recent reviews and more. It does NOT show the number of affiliates or creators per product.

**Why:** covers the listing-age and recent-review part of the SEARCH RULE in the index, which the Shopee API cannot give. Creator count still comes from FastMoss (TikTok side) ([[tiktok-shop-research]], [[shopee-product-finder]]).
the owner (21:53): FastMoss has no Shopee data, so it does NOT serve the Shopee search; drop it for Shopee competition (keep only for TikTok trend spotting). Shopee affiliate counts have no public source; proxy = fast-rising sales, listing age and recent reviews (Konkur) plus the Shopee API once approved.
**How to apply:** it runs only in a browser, and this cloud container cannot run Chrome extensions. Use it on finalists via the owner, or ask whether it has an export or API. Do not assume Claude can read its data.
